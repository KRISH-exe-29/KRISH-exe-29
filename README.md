### ⭐ Flagship: Dispatch Management

The plant's dispatch flow, from the order to the gate.

```mermaid
flowchart LR
    A[Work order] --> B[Packing]
    B --> C[Loading]
    C --> D[Gate pass]
    D --> E[Dispatched]
    B -. delay .-> X[Auto escalation]
    C -. delay .-> X
    X --> R[Role owner notified]
```

**Built with:** 5 user roles, Supabase with PL/pgSQL workflows, and 128 tests.

<details>
<summary><b>Details: shop-floor tools</b></summary>

**Job Lens:** Resume screening that runs in the browser. OCR reads scanned resumes, an offline model ranks them, and the shortlist exports to Excel.

**Test Planner:** Schedules all 40 IEC 60076 transformer tests across multiple units and exports the plan to Excel.

**Industrial Data System:** QR codes tag test records. Four role-based modules, OTP-protected admin and a 3D transformer built in Three.js.

**Hardware Platform v1.3:** Reads a hardware PDF and produces a weighted bill of materials. A 20 to 30 minute task now takes under a minute.

**RTCC & M.Box Tracker:** Tracks pending points and sends follow-ups every 48 hours until they close.

**CapexTrace:** Capex budgets as a work-breakdown tree, so no line can outspend the one above it.

**KioskSentinel:** Offline-first attendance kiosk for 3 shifts that keeps working through power cuts.
</details>

<details>
<summary><b>Details: hardware and IoT</b></summary>

**Intelligent Street Lighting (patent filed, Aug 2025):** Street lights that brighten around a moving vehicle and report their own faults with GPS location. About 60% less energy.

**Flood Alerting System:** Water-level sensing with instant alerts, cutting outage risk by about 90%.

**HWE Automation Tool (Bühler):** Picks feeder classes, loads and I/O in one click for MCC panel design.
</details>

## 📜 My Working Rules

1. **Solve the shop floor's problem.** If nobody on the floor uses it, it isn't done.
2. **Minutes to seconds.** Automate the paperwork so engineers can engineer.
3. **Offline first.** Plants lose power and internet. The software should not care.
4. **Ship, then polish.** A working tool today beats a perfect one next quarter.
5. **Test everything.** Real users, real data, real tests.
